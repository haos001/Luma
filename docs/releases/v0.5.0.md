# Luma 0.5.0 · Your light, your language

Luma now speaks **English and Russian**. Choose a color for your moment, let it fade in, and quit the app while the light stays on.

## New in this release

- **Instant language switching:** open **… → Language / Язык** and choose English, Русский, or Follow macOS. No restart required.
- All 40 preset names and descriptions, recommendation dates, interface labels, app menus, tooltips, accessibility labels, status messages, and USB errors are translated.
- Search for a built-in preset in either language, regardless of the current interface language.
- Your language choice is saved. Existing colors and favorites are preserved; your custom favorite names are never translated.
- Language switching does not send commands to the light. The optional CLI follows the same saved language preference.

## Download & install

Download **Luma-0.5.0-macOS-arm64.zip**, unzip it, and drag **Luma.app** to **Applications**. To update, quit the old version first, then replace it. Your settings stay in your Application Support folder.

| Asset | Contents |

| `Luma-0.5.0-macOS-arm64.zip` | Apple Silicon app, optional CLI, MIT license, and bilingual install notes |

```sh
shasum -a 256 -c Luma-0.5.0-macOS-arm64.zip.sha256
```

**Compatibility:** only the tested ROBOBLOQ `1A86:FE07` USB HID controller (vendor usage page `0xFF00`, 96 LEDs). Not a universal RGB controller. Apple Silicon build; macOS 13 deployment target, Liquid Glass on macOS 26+. Older OS versions and Intel are not validated by this release.

**Signing:** ad-hoc signed, **not notarized by Apple**. Read the included installation guide and [Apple's safe-opening guidance](https://support.apple.com/en-us/102445). Do not disable system security globally.

**Validation:** 17 hardware-free core scenarios, including translation coverage, legacy settings, and unchanged recommendation colors between languages. These checks do not measure physical light output or establish compatibility with other hardware.

## По-русски

**Luma теперь на русском и английском.** Переключение: **… → Language / Язык → Русский / English / Как в macOS**. Интерфейс меняется сразу, выбор сохраняется. Переведены все 40 пресетов, рекомендации, подсказки, статусы и ошибки. Поиск работает на обоих языках, ваши собственные названия цветов не меняются.

Скачайте `Luma-0.5.0-macOS-arm64.zip`, распакуйте и перенесите приложение в «Программы». Перед обновлением закройте старую Luma. Сохранённые цвета останутся. Сборка для Apple Silicon, с локальной подписью, без нотарификации Apple; ограничения совместимости указаны выше.
