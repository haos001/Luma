# Luma 0.4.0 · Set the mood. Close the app.

<!-- Release draft. Publish only after attaching and verifying the assets below. -->

A small native macOS app for a tested ROBOBLOQ USB monitor backlight. Pick a color, enjoy the smooth transition, and quit: the controller keeps the static light while powered.

## Highlights

- 40 presets for work, mornings, evenings, seasons, rest, and creative sessions.
- A local “Recommended now” color based on date, time, and season.
- HSV, RGB, HEX, brightness, and saved favorite colors.
- A color wave in the app, followed by a fade through black into your selected color.
- Native light/dark appearance and Liquid Glass on macOS 26+.
- Optional `lumactl` CLI. No account, telemetry, cloud connection, or background helper.

The app interface is currently in Russian. Installation documentation is available in English and Russian.

## Download & install

Under **Assets**, download `Luma-0.4.0-macOS-arm64.zip`, unzip it, and drag **Luma.app** to **Applications**. No Xcode or package manager is needed.

| File | Purpose |
| --- | --- |
| `Luma-0.4.0-macOS-arm64.zip` | Apple Silicon app, optional CLI, MIT license, and bilingual installation notes |
| `Luma-0.4.0-macOS-arm64.zip.sha256` | SHA-256 checksum for the app archive |
| `Luma-source-0.4.0.zip` | Standalone source bundle; not the ready-to-run app |
| `Luma-source-0.4.0.zip.sha256` | SHA-256 checksum for the source bundle |

To check the app download, put its ZIP and checksum in the same folder and run:

```sh
shasum -a 256 -c Luma-0.4.0-macOS-arm64.zip.sha256
```

## Please read before installing

- **Hardware:** only the tested `1A86:FE07` USB HID controller, vendor usage page `0xFF00`, with a 96-LED strip. Not a universal RGB app; matching USB IDs alone do not guarantee compatible firmware.
- **Platform:** Apple Silicon build. macOS 13 is the deployment target, not a claim of testing on every supported OS. No Intel build is included.
- **Signing:** ad-hoc signed, **not Apple-notarized**. A downloaded app may trigger Gatekeeper. Read the installation notes and [Apple's guidance](https://support.apple.com/en-us/102445); do not disable system security globally.
- **Scope:** static colors and transitions. Continuous effects, screen mirroring, and automatic schedules are not included.
- **Validation:** 13 hardware-free core scenarios pass locally. These do not measure physical color, test the whole interface, or guarantee other controllers will work.
