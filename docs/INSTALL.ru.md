# Установка Luma

[English](INSTALL.md) · Русский

## Готовое приложение

Скачайте `Luma-0.5.0-macOS-arm64.zip` для **Apple Silicon** со [страницы релиза Luma 0.5.0](https://github.com/haos001/Luma/releases/tag/v0.5.0). Сборки для Intel пока нет. Минимальная целевая версия системы — macOS 13; Liquid Glass используется на macOS 26+.

1. Скачайте ZIP и соответствующий файл `.zip.sha256` из одного релиза Luma на GitHub.
2. При желании проверьте контрольную сумму по инструкции ниже.
3. Распакуйте ZIP двойным нажатием в Finder.
4. Перенесите **Luma.app** в **«Программы»** и запустите оттуда.
5. Перед выбором цвета закройте другое ПО, управляющее той же USB-подсветкой.

Для готовой сборки не нужны Xcode и Swift. `lumactl` — необязательная команда для терминала, а не служба. Её можно оставить в распакованной папке или не использовать вообще.

### Проверка архива

Положите ZIP и файл контрольной суммы в одну папку. Откройте Терминал в этой папке и выполните:

```sh
shasum -a 256 -c Luma-0.5.0-macOS-arm64.zip.sha256
```

Ожидаемый результат заканчивается на `OK`. При `FAILED` не открывайте архив: скачайте его заново из нужного релиза. Для следующей версии замените имя файла. Контрольная сумма обнаруживает изменение файла, но сама по себе не подтверждает личность издателя.

### Предупреждение macOS

Сборка подписана локально (**ad-hoc**), но не сертификатом Developer ID и **не нотарифицирована Apple**. Gatekeeper может предупредить о скачанном приложении или заблокировать запуск. Альтернатива — собрать приложение из изученных исходников.

Только если вы проверили источник и доверяете загрузке, следуйте [официальной инструкции Apple для конкретного приложения](https://support.apple.com/en-us/102445). Не отключайте Gatekeeper целиком, не снимайте карантин рекурсивно и не выключайте системные механизмы защиты. Предупреждение об обнаружении вредоносного ПО обходить не следует.

## Сборка из исходников

Нужны Xcode 26+ или соответствующие Command Line Tools, macOS SDK 26+ и Swift 6.2+. Из корня репозитория:

```sh
bash scripts/test.sh
bash scripts/build.sh
open dist/Luma.app
```

Перенесите `dist/Luma.app` в «Программы». Скрипты не устанавливают приложение автоматически и не меняют подсветку.

## Первый запуск

Luma поддерживает **русский и английский**. Откройте **… → Language / Язык**, чтобы переключить язык сразу, или выберите **Как в macOS**. Выбор сохраняется. Названия ваших цветов, RGB и яркость не меняются; настройки версии 0.4.0 загружаются без сброса.

Открытие Luma само по себе не меняет свет. Выберите пресет или свой цвет и нажмите на цветной круг либо «Включить». После завершения перехода приложение можно закрыть — проверенный контроллер сохранит статичный цвет, пока получает питание.

Проверен только конкретный контроллер `1A86:FE07` с лентой на 96 светодиодов. Наличие USB и RGB-светодиодов не означает совместимость. Интерфейс можно изучить без отправки USB-команд в режиме `--preview`.

## Обновление и удаление

Закройте Luma и замените старое приложение в «Программах» новым. Настройки находятся в `~/Library/Application Support/Luma/`, отдельно от приложения. Автоматического обновления нет.

Для удаления закройте Luma и переместите её в Корзину. Папку настроек при желании можно удалить отдельно. Автозапуска и фонового помощника нет. Закрытие и удаление приложения не отправляют команду выключения подсветки.
